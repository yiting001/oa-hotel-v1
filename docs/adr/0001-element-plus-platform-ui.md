# ADR-0001: Element Plus 作为平台管理界面标准

- 状态：已接受
- 日期：2026-07-13

## 背景

现有七张业务单据页面已深度使用 Ant Design Vue，但组织权限、流程设计、表单设计和 A4 打印平台尚未实现。项目现在明确选择 Element Plus 作为长期 UI 组件库。

## 决策

1. 新增平台管理模块只使用 Element Plus。
2. 不再新增 Ant Design Vue 业务页或共享组件。
3. 存量页面按“共享组件 → 应用外壳 → 业务页”的顺序迁移，每个页面完成迁移后删除对应 Ant Design Vue 依赖。
4. 迁移期允许两套运行时共存，但不允许一个页面或一个表单同时混用两套组件。
5. 主题色、间距、打印尺寸和状态色继续由项目 CSS 令牌控制，避免把组件库默认值散落到页面。

## 后果

- 短期会增加构建体积，必须跟踪迁移清单。
- 新平台模块拥有统一的表单、树、表格、抽屉和反馈体验。
- 当最后一个 Ant Design Vue 页面迁移后，删除 `ant-design-vue` 和 `@ant-design/icons-vue`。
