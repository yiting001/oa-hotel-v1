# 行政、物资与人力表单

## 1. 印章证照外借申请表

来源：[image10.png](../../assets/source-forms/image10.png)

| 字段 | 类型 | 规则 |
| --- | --- | --- |
| 申请人 | User | 默认当前用户 |
| 部门 | Department | 默认当前部门 |
| 日期 | Date | 默认当前日期 |
| 使用日期 | Date | 必填 |
| 归还日期 | Date | 必填，不早于使用日期 |
| 陪同人 | User[] | 按制度选择 |
| 前往地点 | String | 必填 |
| 印章证照名称 | SealLicense[] | 必填，来自资产台账 |
| 申请内容 | LongText | 必填 |
| 相关附件 | Attachment[] | 支持多文件 |
| 审批意见 | ApprovalTimeline | 系统生成 |

审批完成后进入外借执行状态，印章管理员还需登记：

- 实际领用人、领用时间
- 实际归还时间
- 归还状态、异常说明
- 交接双方确认

这些属于执行记录，不替换原申请字段。

## 3. 物资申购单

来源：[image12.png](../../assets/source-forms/image12.png)

### 3.1 表头

| 字段 | 类型 | 规则 |
| --- | --- | --- |
| 申购人 | User | 默认当前用户 |
| 申购部门 | Department | 默认当前部门 |
| 申购日期 | Date | 默认当前日期 |

### 3.2 申购明细

支持增加行、删除行；至少一行。

| 字段 | 类型 | 规则 |
| --- | --- | --- |
| 品名 | String/Item | 必填 |
| 品牌 | String | 可选 |
| 规格型号 | String | 必填 |
| 单位 | Unit | 必填 |
| 申购数量 | Decimal | 大于 0 |
| 月消耗数量 | Decimal | 大于等于 0 |
| 参考单价 | Money | 大于等于 0 |
| 备注 | String | 可选 |

### 3.3 汇总

| 字段 | 类型 | 规则 |
| --- | --- | --- |
| 申购部门含税单价合计 | Money | 系统计算或采购核定 |
| 申购部门含税金额合计 | Money | 数量乘含税单价后汇总 |
| 审批意见 | ApprovalTimeline | 系统生成 |

采购执行价和申购参考价应区分字段，避免审批后覆盖原始申购依据。

## 4. 领用申请单

来源：[image13.png](../../assets/source-forms/image13.png)

### 4.1 表头

| 字段 | 类型 | 规则 |
| --- | --- | --- |
| 单号 | String | 自动生成 |
| 填写日期 | Date | 默认当前日期 |
| 部门 | Department | 必填 |
| 联系人 | User | 必填 |

### 4.2 领用明细

| 字段 | 类型 | 规则 |
| --- | --- | --- |
| 货物编号 | String/InventoryItem | 从库存项目选择 |
| 品名 | String | 自动带出 |
| 规格 | String | 自动带出 |
| 单位 | Unit | 自动带出 |
| 请领数量 | Decimal | 大于 0 |
| 实发数量 | Decimal | 库管节点填写，不得超过可用库存 |
| 用途 | String | 必填 |

### 4.3 其他

| 字段 | 类型 | 规则 |
| --- | --- | --- |
| 附件 | Attachment[] | 可选 |
| 审批意见 | ApprovalTimeline | 系统生成 |

审批通过不等于已出库。应区分“审批完成、待发放、部分发放、已发放、取消”。

## 5. 款待申请单

来源：[image14.png](../../assets/source-forms/image14.png)

| 字段 | 类型 | 规则 |
| --- | --- | --- |
| 申请部门 | Department | 必填 |

| 事由 | LongText | 必填 |

## 6. 员工请假审批单

来源：[image22.png](../../assets/source-forms/image22.png)

| 字段 | 类型 | 规则 |
| --- | --- | --- |
| 姓名 | User | 默认当前用户，代申请时可选 |
| 工号 | String | 从员工档案带出 |
| 部门 | Department | 从员工档案带出 |
| 职务 | Position | 从员工档案带出 |
| 填单时间 | DateTime | 自动生成 |
| 请假类别 | LeaveType | 年假、事假、病假等字典 |
| 其它说明 | String | 选择“其它”或规则要求时必填 |
| 休假时间 | DateTimeRange | 必填 |
| 天数 | Decimal | 根据工作日历计算，可由 HR 校正 |
| 请假原因 | LongText | 必填 |
| 审批意见 | ApprovalTimeline | 系统生成 |

需要与员工假期余额、工作日历、跨天计算和销假状态关联。流程不能只固定到部门总监，应支持按天数、职级和请假类别分支。

## 7. 行政与物资台账

这些申请表背后需要业务台账，否则只能完成审批，无法形成闭环：

| 台账 | 最小字段 |
| --- | --- |
| 印章证照台账 | 名称、类型、编号、保管人、状态、有效期 |
| 外借台账 | 申请、领用、计划归还、实际归还、异常 |
| 用印台账 | 申请、印章、份数、执行人、执行时间、归档号 |
| 物资目录 | 编码、品名、规格、单位、分类、启停状态 |
| 库存台账 | 物资、仓库、可用量、占用量、批次 |
| 采购执行 | 申购、供应商、询价、订单、到货 |
| 假期台账 | 员工、假期类型、年度额度、已用、冻结、余额 |
