## 5. 字段完整性策略

1. 截图中的字段逐项进入字段字典。
2. OCR 结果经过放大图片人工核对。
3. 原文模糊或矛盾内容不擅自定值，进入待确认清单。
4. 系统级字段与截图字段分开记录，避免误认为原表字段。
5. 后续 UI 验收以截图、字段字典和实现页面三方对照。
